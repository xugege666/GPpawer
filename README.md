# Alpha Lab

苹果 iOS 玻璃质感的股票策略研究工作台。React 19、TypeScript、Vite，所有回测在浏览器本地运行。

## Windows 本地使用

推荐安装 [Node.js 24](https://nodejs.org/)，安装后重新打开终端或启动脚本。

### 使用已构建的本地 ZIP 包

将 ZIP 包内容解压到 `C:\Users\xwm\Desktop\LiangHua`，确保 `package.json`、`start-local.cmd` 和 `dist` 文件夹直接位于该目录内，不要多套一层项目文件夹。

双击 `start-local.cmd`，脚本会启动服务并尝试打开浏览器。访问地址为 `http://127.0.0.1:5173`。运行期间保持命令窗口打开；按 `Ctrl+C` 停止服务。ZIP 已包含 `dist`，只需要 Node.js，无需先执行 `npm ci`。

也可以在该目录打开 PowerShell 或命令提示符，执行：

```powershell
npm start
```

`npm start` 使用 Node.js 自带模块提供本地静态服务，不需要安装 npm 依赖；浏览器需手动打开上述地址。

### 使用 Git 仓库源码开发

Git 仓库不包含 `dist` 和 `node_modules`。将源码放到上述目录后，双击 `start-dev.cmd`：首次会执行 `npm ci`，随后启动开发服务；存在 Vite 依赖时跳过安装。浏览器打开 `http://127.0.0.1:5173`。

如果需要从源码生成供 `start-local.cmd` 使用的生产版本，在项目目录执行：

```powershell
npm ci
npm run build
```

脚本会保留已有项目文件，安装和构建输出遵循项目配置。若端口 5173 被占用，先关闭占用该端口的旧服务再启动。浏览器策略记录保存在当前地址的 localStorage 中；更换端口或浏览器后不会自动迁移，可先导出报告。

## 开发与验证

需要 Node.js 22.12+（建议 Node.js 24）和 npm。

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

开发服务启动后，在本机打开 `http://127.0.0.1:5173`。云工作区可使用 `npm ci --cache /workspace/.npm-cache`，将依赖缓存放在可写目录。此项目使用现有 checkout，每个云任务已隔离，无需另建 Git worktree。

```bash
npm run build     # 类型检查与生产构建，输出 dist/
npm start         # 用无依赖 Node.js 静态服务器运行已有 dist/
npm test          # 回测引擎单元测试
npm run test:e2e  # 浏览器交互测试，需要先启动开发服务
npm run preview  # 用 Vite 查看生产构建，需要安装依赖
```

浏览器测试默认使用 `/usr/bin/chromium`；其他机器可通过非敏感变量 `CHROMIUM_PATH` 指定本机 Chromium 可执行文件。测试记录写入被忽略的 `test-results/`。界面截图保存在 `artifacts/`。Windows 启动脚本采用 ASCII 和 CRLF，当前验证环境为 Linux，未在 Windows 命令提示符实际执行。

## 已实现

- 研究总览：三种策略模板、累计/年化收益、最大回撤、夏普比率、收益与回撤曲线。
- 参数设置：资金、长短窗口、费用、仓位和止损；调整后立即重新回测。
- 策略实验室：保存、恢复、删除本地策略；刷新后保留。
- 组合与风控：当前策略资金分布、仓位规则、年度收益。
- 交易记录：买卖过滤、分页、成交原因和已实现盈亏。
- JSON 完整报告与 CSV 交易记录导出、快捷搜索、手机布局和键盘操作。

## 数据与回测边界

使用固定种子的**合成行情**，不对应任何真实股票。数据截止 2026-09-30，支持 252/756/1260 个工作日日线观察点，未模拟交易所节假日。界面持续标记模拟数据。

信号只使用当日及之前的数据，于下一工作日开盘执行。买入按 100 股整手，双边手续费计入现金流；持仓收盘触发止损后，下一日开盘退出。价格上涨导致超额仓位时，下一日按仓位目标减仓。最大仓位是执行时的目标，无法保证盘中或跳空后从不超过它。

累计收益按期末净值计算；年化收益和波动率使用 252 个交易日；夏普的无风险利率设为 0。交易胜率只统计完整持仓周期，累计该周期内部分减仓的盈亏，排除期末未平仓持仓。基准为首个观察点收盘买入并持有，不计成本。首个观察点净值为 1，首笔策略成交最早在下一个工作日开盘。

模板规则可在「研究指南」查看。当前没有实时行情、券商下单、滑点、复权、停牌、涨跌停、历史股票池、自动样本外检验或多资产组合；这些需要后续接入和独立验证。

保存的策略仅存于当前浏览器的 localStorage。清理浏览器数据会移除记录，可用 JSON 导出保留完整报告。当前不依赖账户、服务器、数据库或任何密钥。
